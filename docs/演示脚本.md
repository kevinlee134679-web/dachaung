# 虚构全平台演示脚本

先按[运维文档](运维.md)与[本地网站配置](本地网站配置.md)准备环境。所有药品、剂量、日程、问卷和发言都只作虚构流程演示，不使用真实患者资料。默认服务回环本机，未经配置不是公网网站。

1. **首次使用**：执行 `init-demo` 后启动 `serve`，浏览器打开 `http://127.0.0.1:8000/`。选演示患者甲登录，五个顶部导航为：**首页**、**用药管理**、**药学知识**、**支持服务**、**我的**。初始化脚本已为患者甲预置两周虚构故事数据（3 种药品、已生效计划、近 14 天服药记录、2 段支持对话与 1 份完成评估的问卷结果）。
2. **O 问卷与用药清单**：进入「我的 → 依从性类型」，点击「重新评估」或对空白账号点击「开始评估」，确认隐私说明弹窗后按一屏一题作答（Q1–Q3、Q5–Q7 可选「无法判断」，Q5 前可点「跳过选填部分」），本人提交后自动生成结果卡片。进入「用药管理 → 用药清单」，可选已有药品或「新增药品…」，或展开「AI 病历识别」上传/选择病历（PDF、PNG、JPEG）并填入清单；点击「保存并生效」一次完成保存草稿、提交并发布正式计划。家属无确认发布按钮。
3. **A 服药记录与报告**：进入「用药管理 → 今日用药情况」，对当日时段点「已服」「没服」（选漏服原因与可选备注后点「记录没服」）或「不确定」，在下方「服药记录」查看记录与漏服原因，也可通过「补记服药情况」补记。进入「我的 → 用药报告」，统计与摘要每次读取时实时计算，点刷新重新读取；没有已到时计划时段时分母为 0、比例不可计算，不展示虚构达标率。通知与任务须由 `worker` 或管理员显式执行，关闭页面不保证系统推送。
4. **B 对话与减负**：进入「支持服务 → 支持对话」新建自由对话时，空会话显示 4 个开场选项，点击或输入消息即可发送。未配置外部模型（`LLM_MODE=mock`）时显示模拟回复，配置 `LLM_MODE=real` 时调用外部模型；输入危机相关短语会直接触发固定安全回复。支持主动使用「使用极简模式」，刷新仍保持，可点击「恢复普通模式」。管理员未选择患者时在「我的」打开控制台，可显式检查模拟模型（零网络），并对受控案例触发 `empty_response`、`invalid_json`（每轮最多 2 次尝试，仅空或非法输出重试）或 `llm_timeout`（超时记为 `outcome_unknown`，返回 409 须核查原记录，不能重试或重置抹去）。
5. **C 授权查看与服务记录**：进入「我的 → 授权与服务」，可查看「服务授权」与「服务记录」。对已有正式服务可查看流转状态并填写三维自愿反馈；管理员在「我的」控制台输入任务或服务编号可模拟派发与按合法顺序流转状态。
6. **同辈互助**：患者进入「支持服务 → 匿名同辈」，查看可用小组及其状态；本人匿名身份与可交流状态由服务端通过 `GET /api/v1/peer-memberships/me` 恢复。界面不提供入组入口，演示库中的患者也不是小组成员，因此发言、审核公开与退出只由接口测试覆盖（见[验收用例](验收用例.md) C-03）。
7. **家庭授权**：患者在「我的 → 授权与服务 → 家庭授权」生成单次限时绑定码，家属登录兑换后不具备默认健康权限。患者勾选精确 `scope` 并保存；例如只授 `dialogue:read` 时，家属可查看对话历史但不能代发消息或切换模式。患者撤销后，家属刷新与原接口会话立即失去该权限。
8. **恢复与交接**：分别 Ctrl+C 停止 Web 与 worker，使用同一数据库重新 `serve`，展示会话、服药记录、服务与模式历史。升级前停止全部写入，执行 `migrate --stopped` 先备份再迁移。不要对已有库再次 `init-demo`，不删除未知结果或历史来重演。

## 独立可重放的统计场景

以下在已配置 CPython 3.14 的环境中、于 `backend/` 目录执行。数据准备通过显式可控时钟和真实业务 API，启动网页恢复正常实际时钟；不冒充连续多日现场观察。

```sh
uv run python -B -m medplatform.demo.medication --database test-output/report-demo/demo.sqlite3
uv run python -m medplatform serve --database test-output/report-demo/demo.sqlite3 --port 8001
```

患者甲→「我的 → 用药报告」，按生成器输出的 `window_start`/`window_end` 选择北京时间日期后读取：14 个已到时段、10 次本人确认，开盒证据独立。在另一个终端执行（同库新来源，不清空）：

```sh
uv run python -B -m medplatform.demo.medication --database test-output/report-demo/demo.sqlite3 --add-late-report
```

点刷新重新读取为 11/14；同一迟到来源重复执行仍为 11/14，按原 `as_of` 由计划与事件历史重算仍为 10/14。此场景专注 A，未 seed 其他模块时其目录显示未就绪属于真实边界。
