# 任务调度说明（S03实际实现）

当前仅显式API/CLI维护和执行一次，Web导入/启动/GET不启动runner。S06获明确指令后才接单runner的5秒轮询；本期没有后台常驻可靠推送。统一命令、演示和接口定位见S03/运行与交接.md。

- A维护Task/Execution/TaskLease/回执，O控制提醒业务。注册payload为A01/F03精确定义；B/C业务处理器未接入，相关请求明确拒绝，不能指定Python、命令、URL或自造第三方事实。
- 短事务条件领取，90秒租约/15秒续租/递增claim_token；处理适配在写锁外，结果需仍持令牌和适用版本。SQLite忙最多5秒503，不无限等待；已确定本地计算失败回滚后立即结算失败/安全重试，存储不可用保持现场待显式恢复。
- 总3次含首次、仅确定无副作用可60秒后安全重试。outcome_unknown不自动重发，B未来预算独立，不能借A重试重置。当前所有已注册可执行适配为本地事务，崩溃后可证明未提交的尝试由显式维护安全结算；真实外部动作将来必须登记side_effect_started并按未知策略核查，当前未启用。
- 同来源业务键唯一Task，同task一次attempt唯一Execution，同run键在途409/重放同结果。取消pending/retry_wait可终止，running先记录请求，安全点确认，不能伪称撤回已发生副作用。原scheduled_at/valid_until不因恢复重新计算。
- 来源事实与ChangeNotice同库；A仅消费已注册plan/event变更，核对权威引用，目标物化/失效记录和NoticeConsumption同事务且notice+consumer唯一。B/C消费者/周期节点/模式维护未实施；不把未接入通知伪记成功消费。
- O的daily/weekly/AsiaShanghai稳定单药slot，物化≤31日、裁剪生效区间；GET缺覆盖409。提醒默认关闭，初次/重复/稍后合计≤3，重复30—120分钟/最多2；锚点[-60,60]且距原dose≤60分钟，未知严格/餐时或不满足原最小间隔不偏移。不改医嘱/计划时间或猜医学时间窗。
- 普通通知只在原通知后30分钟内且未到下一正式时段补发；稍后由用户明确操作，5—120分钟，早于原dose+4小时/下一slot；不当作延迟服药。偏好、质量/明确患者处理、计划/授权、当前时效逐次重验；notify_family需原同意和有效notify:receive，接收方/Grant引用同提交记录。
- 本地in_app提交持久化notification/result_ref和接收方引用，状态submitted，不声称delivered/展示/响应。真实渠道A40未配置独立认证签名即拒绝；受控内部mock回执保留去重/乱序/过期审计，不能认定真实送达。期满不自动补发或恢复终态。

演示时钟仅用于隔离虚构fixture/测试；普通服务使用实际UTC、按Asia/Shanghai展示和排程，患者展示时区变化不移动既有医嘱。现有默认库没有自动升级，先停服务备份后显式migrate；绝不改0001—0003、清库或删除历史。
