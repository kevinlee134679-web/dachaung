# 数据字典与存储参考

字段级契约参见 [确认契约目录](contracts/)，接口索引参见 [全平台接口目录 v0.1](contracts/全平台接口目录_v0.1.md)。

## 跨领域数据不变量

- 类型与环境隔离：SQLite 表开启 `STRICT` 约束；关键表包含 `data_environment`（`demo` 或 `real`）与 `is_simulated`（布尔值）字段隔离演示与真实环境，当前仅开放 `demo` 模式。
- 时间戳与时区：时间戳由 `backend/medplatform/core/documents.py` 的 `stamp` 写成微秒级 UTC ISO 8601 字符串（如 `2026-01-01T00:00:00.000000+00:00`）；用药计划、日历与依从性时段计算基于 `Asia/Shanghai` 时区，展示时区变更不移动已有医嘱与已物化时段。
- 原始事件与修订追加：原始采集事实持久化于 `source_events`，保留原始 JSON 载荷；区分手工上报（有 `reporter_account_id`、无 `device_id`）与设备采集（有 `device_id`、无 `reporter_account_id`）；修正、补充或撤回通过 `event_revisions` 追加修订快照。
- 幂等控制与凭据保护：跨域写操作通过 `idempotency_receipts` 记录状态（`processing`、`committed`、`rejected`、`expired`），通过 `receipt_responses` 缓存响应快照；敏感认证与临时凭据在 Windows 下使用 DPAPI 保护，POSIX 下使用私有 AES-GCM 密钥保护，对外回执不存明文。
- 授权校验与归属隔离：服务端依据登录会话、实时家庭成员绑定与授予的 Grant 权限动态校验；请求中 `patient_id` 仅用于归属核对；家庭成员绑定不默认授予健康数据访问权限。
- 未适配方法：画像中的 CAS 由 `backend/medplatform/profile/questionnaire.py` 的 `unavailable_cas` 固定写为 `status=unavailable`、`value=null` 并附原因；支持强度映射未接入，`/api/v1/health` 的 capabilities 标为不可用。

## 公共基础设施与审计数据表

- `schema_migrations`：结构迁移版本历史与校验和
- `operation_audit`：写操作与审计记录
- `dose_slots`：正式用药计划物化时段索引
- `source_events`：原始采集事件事实
- `event_revisions`：原始采集事件修订历史
- `evidence_slot_links`：服药事件与用药时段关联

## 域 O：身份、授权与画像数据表

- `o_accounts`：系统用户账号
- `o_sessions`：用户登录会话
- `o_binding_codes`：家庭成员绑定码（只存哈希）
- `s02_documents`：身份、画像与用药文档
- `s02_document_history`：业务文档历史版本快照
- `s02_source_keys`：附件与外部凭据唯一索引
- `idempotency_receipts`：写操作幂等状态收据
- `receipt_responses`：幂等请求响应快照缓存
- `change_notices`：领域事件变更通知
- `o_schedule_windows`：用药计划版本时段区间
- `o_revocation_audit`：绑定解绑与撤权审计日志
- `o_demo_support_recipients`：演示预置支持服务接收主体
- `o_sharing_scopes`：服务数据共享授权范围
- `o_sharing_scope_history`：共享授权范围变更历史
