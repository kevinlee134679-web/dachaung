## 可重复的本地演示

1. 患者甲进入“我的→八题问卷”，逐题选择、排序、保存。支持不清楚/不适用，not_answered可保存但不能提交；每次只显示一个主题。提交后主动生成描述性画像，CAS/value、模型/预处理/分类方法版本仍null，主要分类为空。更正建立新回答并引用原回答，旧回答/画像保留。
2. “用药管理→药品资料”添加虚构药品名称。资料编辑不接收剂量和频次。“病历资料”可上传1—10MiB的PDF/PNG/JPEG，读取需独立files:read；不会OCR、不会据此自动识别医嘱。
3. “资料核对”人工填写草稿，可先留null并保存，修改产生新的content_revision。提交的是精确内容修订，状态为等待本人核对；患者本人核对完整资料后显式选择未来生效点和是否更新已有计划。正式版本、A正式引用、31日单药原子slot及plan_published通知同库提交。资料不完整时由O返回需修改，不能留下半份正式计划。
4. “今日安排”只读已物化的正式时段；每药一次一slot，多药同刻不合并。不显示假服药状态或确认比例；超出物化覆盖窗口明确未就绪，不在GET补写。每日/每周、Asia/Shanghai、含首尾条目日期与未来替换按既有契约执行；显示时区改变不移动旧计划。后台滚动物化/提醒执行在S03接入，长期窗口不能靠页面补齐。
5. “提醒设置”保存启停、作息、锚点、重复、稍后及隐私时段等偏好。本阶段不计算或发送任务，不移动scheduled_at；每剂医学/下一时段/通知频控与当前授权检查由S03执行前完成。系统通知、声音及振动未接入，选择其能力会明确拒绝。隐私开启时采用已确认中性文案（null或“今日事项待确认。”“有一项日程需要处理。”），其他自定义文字拒绝，避免声称已核验未知病药名。通知家人另需本人及有效notify:receive授权。
6. 患者在“家庭授权”发5分钟一次性码；家人账号兑换只建立关系，不默认授权。患者另勾选精确范围并明确保存，家人随后可在当前对象选择框切换。一个账号可同时管理本人和多名已授权患者；撤销授权与解除关系分开，解除关系使相应授权同时失效。家人不能发布正式计划、主动生成患者画像或把代答伪装成本人。

可用 `.\.venv\Scripts\python.exe -X utf8 scripts/create_demo_document.py` 生成test-output/fictional-record.pdf。文件明确写“FICTIONAL DEMO DOCUMENT”，不包含真实患者或医嘱；生成器拒绝覆盖已有文件。该运行产物不上传。浏览器本轮实际验证了登录/刷新恢复、八题/排序/提交、描述性画像、药品/草稿/正式计划/日程、虚构PDF上传、提醒保存、退出及家庭入口；家庭兑换/授权/撤销的完整边界由HTTP接口测试验证，没有冒称整段已用浏览器跑完。

## 会话、幂等与数据保护

本地会话绝对8小时，不滑动续期；Cookie为HttpOnly/SameSite=Lax/Path=/，HTTPS响应时设置Secure，但当前仅本地HTTP服务，没有已部署TLS或生产认证。Cookie及CSRF不放localStorage、日志或普通回执。令牌仅保存哈希，当前CSRF及敏感回执使用Windows当前账户DPAPI并绑定上下文；没有跨账户或明文回退。损坏密文/原OS账户不可用时503，不能另造会话或绑定码。此实现参考[Microsoft DPAPI接口](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)并已在本机实际验证。

所有业务写入检查同源Origin、会话CSRF、稳定Idempotency-Key以及实时患者归属/Scope。登录只对固定虚构白名单开放，不能把账号头、请求body或Scope字符串当认证。普通回执与业务同事务；同键异内容409、在途409+Retry-After:1，旧键到期409。重放前重验当前底层权利；退出/到期不凭旧登录键恢复。

以下显式维护清除过期响应正文/敏感载荷，保留最小回执墓碑、指纹和业务引用，不删业务事实：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m medplatform expire-receipts
```

普通完整回执保留7天；敏感载荷不超原会话8小时/原码5分钟，码已消费或会话已撤销则不能重放。没有启动时自动清理或墓碑删除机制；实际数据留存仍是既有专项，不能用清回执制造重复业务。浏览器只保存对象引用、待核查操作键和上传来源引用，不保存健康正文或会话凭据；网络未知时保留原键，先查原资源。

文件路径由UUID生成，原名仅显示。暂存校验、不可变内容位置及DB引用按实际结果返回；失败事务不暴露半文件，不误删旧有效文件。中断可能留下不可公开的孤立pending/blob；当前不自动删除，停服务后先按数据库引用和完整性核对，再按明确留存/清理要求处理，禁止盲删整个files-demo目录。该维护限制不影响已验证的保存、授权读取或回滚语义。
