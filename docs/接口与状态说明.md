# 实际接口与状态 / S02（应用0.2.0）

本文件是实际实现索引，不新增业务契约。当前共42条API：S01的G01/G02，加O01—O31与A01—A09。完整输入/方法/路径清单及实际输入JSON Schema见[interface-manifest.json](S02/interface-manifest.json)；QuestionAnswer.value还由questionnaire.py按各题完整字段、互斥/排序/范围校验，不能把通用dict Schema当成允许任意字段。输出及R/O/null/默认逐字段继承S00的01_公共基础与O字段、A01_字段及当前有效增量，未额外给无Meta对象塞Meta。

| 已实现卡 | 能力与维护方 | 关键限制 |
| --- | --- | --- |
| G01/G02 | A公共健康/配置 | schema0003必要表检查；G02仅可信管理员，模型连接未验证，不输出配置密钥/路径 |
| O01—O07 | O会话/本人及管理对象/基础资料 | 固定虚构登录、8小时、受控退出回执；当前对象不覆盖请求明确路径；PATCH保留省略字段 |
| O08—O14 | O家庭关系/精确Grant | 码一次5分钟；兑换无默认Scope；本人授权，关系与授权撤销分别留历史；到期状态只读投影 |
| O15—O19 | O八主题定义/作答 | initial-v0.1；完整8键快照；unknown/not_applicable可提交，not_answered阻止；提交后只新建更正副本 |

| A05—A09 | A人工草稿/内容修订/提交 | editing/returned可编辑，pending/confirmed锁定；仅O写正式引用；资源revision与content_revision分离 |

全部响应request_id/status/data/error；成功error=null，失败data=null且error只code/message。每次请求新request_id，X-Request-ID一致；未知API是JSON404，无首页回退。无查询卡拒绝未知/重复查询，JSON拒绝未知字段/重复属性/NaN/Infinity；无时区时间422。ID、来源事件、幂等键和操作审计ID互相独立。

未登录401；已知家庭对象Scope不足403；跨患者资源404；旧修订/冲突/过期/在途409；无效结构422；超限413；类型415；必要存储/原文件/敏感解密不可用503；异常脱敏500。任何失败都不当成空列表、零比例或“已审核”。在途附Retry-After:1；SQLite忙等待最多5秒，明确503而非无限等待。

所有列表默认20/最大100，按卡中稳定顺序；游标使用受保护载荷，绑定账号、患者、操作、筛选和最后排序位置，不能把甲游标用于乙或另一类资源。读取、写入和重放各查当前权限；后续执行/回调须复用相同O权威边界。

合法状态：会话有效→注销/到期；绑定码创建→消费/到期；关系active→revoked且不可恢复；Grant内容更新增版本，撤销/到期后重授权新事实；问卷draft→submitted；画像新结果保留旧结果；草稿editing/returned→pending_confirmation→confirmed，资料不完整由O登记returned及原因；正式版本confirmed→superseded并按新生效点关闭旧区间，处方内容快照不改，未来旧slot置superseded，历史证据不改挂；提醒配置显式新修订。每次有效变更在s02_document_history保存完整旧/新文档。

C40画像fixture、F-API01稍后任务、A10以后记录/统计/执行、B/C业务都没有实现；154卡契约目录不是154条已部署接口。药学知识入口明确尚未接入B2适用审核资料；未造医学内容或共享知识库。完整运行/权限/限制及S03要求见[S02交接](S02/运行与交接.md)。
