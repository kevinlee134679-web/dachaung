# C v0.3 本人同辈恢复与资源展示增量

2026-11-18，Asia/Shanghai。依据用户明确授权的《S05 第五批补充指令：三项业务确认及待确认清单更新》。C-v0.2、C-v0.1 及其已确认的字段、接口与状态继续有效。本增量落实以下三项决定。

## 1 本人恢复匿名成员

本人登录后由服务端依据 O 当前权威身份恢复属于自己的匿名成员记录和当前修订。退出后仍可查看本人历史。持久化成员状态和当前是否可交流分别投影。读取不恢复成员资格，也不改变服务或共享授权。家属的授权只允许既有组级介绍。

### C41 读取本人匿名成员记录

| 项目 | 定义 |
| --- | --- |
| 方法与路径 | `GET /api/v1/peer-memberships/me` |
| 身份 | 已登录且当前对象为账号 O 本人，核验 `peer:read`、虚构环境及患者归属。调用方不能指定患者、账号或成员标识。 |
| 参数 | 无路径参数和请求体。`cursor` 可省略，`limit` 默认 20，范围 1–100。只接受这两个查询字段。 |
| 返回 | HTTP 200，公共四字段 Envelope，data 为 `{items, next_cursor}`。没有本人记录为 `items=[]`、`next_cursor=null`。 |
| 失败 | 未登录 401 `AUTH_REQUIRED`。非本人上下文 403 `PEER_MEMBERSHIP_REQUIRED`。非法字段或分页位置 422。必要存储不可用时沿用公共 503。 |
| 读取、顺序及分页 | 只读本人记录，按 `membership_id` 稳定分页。游标沿用 O 受保护游标，绑定读取账号、当前本人和 C41。返回禁止缓存。 |

`items` 每项字段均必填且不可空。当前参与状态与是否可交流来自已有 C 成员、当前小组资源和 O 权威授权。匿名帖子继续沿用 C20 的原投影。

| 字段 | 类型 | 来源 |
| --- | --- | --- |
| `membership_id` | ID | 本人成员记录编号 |
| `group_id` | ID | 本人入组关联小组 |
| `service_id` | ID | 原唯一正式入组服务 |
| `alias` | ShortText | 组内随机昵称 |
| `status` | enum | 原 `pending`、`active`、`left` |
| `revision` | Version | 原成员 `meta.revision`，C19 用它作期望修订 |
| `can_participate` | boolean | 仅当前成员为 `active` 且当前小组和权威授权仍允许时为 `true` |

本人历史仅返回上述字段。

## 2 同级资源稳定展示

C01 匹配规则沿用第一批。所有合格候选按稳定资源编号顺序展示，可打开各自的精确版本。已有结构的选项栏位继续采用原字段限制，超出栏位的候选经已有资源引用全部呈现。此顺序只用于展示，保持同级和非临床排名的含义。

## 3 B 建议转草稿延期

B 对话建议生成或预填 C 草稿以及草稿 `source_suggestion_id` 的启用正式延期。建议类型、有效期、主动采纳方式和 B 案例重置保护的新增设计留待单独确认。既有 B23/B24 照常适用。B23 核验精确草稿修订及当前有效本人确认，共用 C07 唯一创建。B24 读取 C 当前状态。
