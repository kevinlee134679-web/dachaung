# S01 实际接口与下阶段交接

本期仅A0/A1公共底座、基础页面和记录机制。全平台154张有效接口卡见 `../contracts/全平台接口目录_v0.1.md`，不等于154条已经实现。本阶段只有下面两个生产API，未增加公共业务取舍。

| 卡 / HTTP | 已实现行为 | 权限 / 错误 |
| --- | --- | --- |
| G01 GET /api/v1/health | 成功data含process_status/readiness/dependencies/app_version/checked_at，检查连接、schema版本与必要表；只读 | 无Cookie、无查询；不可用503 DEPENDENCY_NOT_READY，data=null；不输出库路径/建库/迁移 |
| G02 GET /api/v1/config/status | 成功data含auth_mode/llm_mode/requested_pipeline/model_configured/model_connectivity/capabilities/version_refs；不探测模型 | 当前服务端白名单管理员；未登录401，非管理员403 ADMIN_REQUIRED；默认无账号，正常启动401；schema故障503；无URL/密钥/凭据或内部路径 |

统一四字段request_id/status/data/error；服务端生成request_id并放X-Request-ID，成功error=null，失败data=null且error仅code/message。未知API是JSON404，不回退首页；非法查询422，不接受自报身份。配置状态中的model_configured只是配置完整性，model_connectivity=unverified；业务能力均关闭。

GET `/` 与 `/static/*` 提供同源原生页面和资源。首页、用药管理、支持服务、积分权益、我的五个导航仅显示本阶段状态；没有假患者、余额、疗效、已联系或已送达。CSP只允许本源，无CDN/外部字体/内联脚本。

身份模块 `medplatform/auth.py` 为进程内可信demo适配骨架；`storage.py` 的授权读适配仅内部使用，没有A录入查询公共路由。测试专用POST/抛错路由只存在测试局部app中，不注册到正式应用。幂等键格式、CSRF及Origin入口已验证，回执/墓碑/敏感OS幂等还未实现。S01没有公开演示登录、家庭授权维护、问卷画像、正式计划、服药统计、提醒投递、B对话、C服务或账本；不能把健康ready当成全平台就绪。
