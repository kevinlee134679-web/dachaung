# 本地网站配置

本指南面向本地开发与演示环境。后端使用本机 SQLite 数据库，支持 CAS 问卷与可选 CPU 模型预测，以及可选的外部大模型（用于 AI 病历识别与 AI 支持对话）。以下示例命令以 Windows PowerShell 为例，在 macOS/Linux 下可对应使用 `./start.sh` 与 POSIX 路径。

## 运行环境

| 组件 | 要求或配置来源 | 用途 |
| --- | --- | --- |
| CPython、uv | CPython 3.14（由 `backend/pyproject.toml` 与 `medplatform/__main__.py` 约束），依赖锁定在 `backend/uv.lock` | 运行后端服务与管理命令 |
| Node.js、pnpm | `pnpm` 版本与脚本见仓库根目录 `package.json`，依赖锁定在 `pnpm-lock.yaml` | 构建前端产物到 `backend/medplatform/static` |
| 基础模式 | `APP_ENV=local`、`AUTH_MODE=demo`、`LLM_MODE=mock` | 本地虚构账号、模拟对话、CAS 自报计分与解读卡片 |
| CAS 模型预测（可选） | `backend/pyproject.toml` 的 `cas` 依赖组（`numpy`、CPU 版 `torch`），开关为 `CAS_RETRAINED_BUNDLE` | 根据本人填写的 Q5–Q8 运行本地推理 |
| 外部模型（可选） | `LLM_MODE=real`，同时配置 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY` | 启用 AI 病历识别与外部大模型支持对话 |
| 地址与存储 | 监听 `127.0.0.1`，默认端口 `8000`（`PORT` 或 `--port` 可改） | 默认数据库为 `backend/var/app-demo.sqlite3` |

## 首次启动

安装前后端依赖并构建前端产物。前端改动后需重新运行 `pnpm build`。

```powershell
pnpm install --frozen-lockfile
pnpm build
Set-Location backend
uv sync --locked
```

如需启用本地 CAS 模型预测，在同一个 `backend` 目录安装 `cas` 依赖组并指定模型包目录；只做自报计分与解读卡片时可直接进入建库步骤。

```powershell
uv sync --locked --group cas
$env:CAS_RETRAINED_BUNDLE = (Resolve-Path 'data/models/cas-dl2-retrain-20261124').Path
```

首次使用默认数据库时初始化一次。若已有演示库，下面的判断会保留既有账号、计划与记录；旧版数据库提示需要迁移时，按[运维指南](运维.md)备份并执行 `migrate --stopped`。

```powershell
if (-not (Test-Path 'var/app-demo.sqlite3')) {
    uv run --locked python -B -X utf8 -m medplatform init-demo
}
uv run --locked python -B -X utf8 -m medplatform serve
```

启用 CAS 模型预测时，使用 `uv run --locked --group cas python -B -X utf8 -m medplatform serve` 启动。

浏览器打开 `http://127.0.0.1:8000/`。`init-demo` 会使用虚构账号、支持资源、同辈小组及患者甲的两周故事数据初始化数据库。

## 用药安排与 AI 病历识别

在「我的 → 药品资料」可维护药品，也可直接在「用药管理 → 用药清单」选择已有药品或选择「新增药品…」。填写剂量、每日或每周服药时刻、起止日期及用餐要求后，点击「保存并生效」即可在单次操作中完成保存草稿、提交并发布正式计划，随后在「用药管理 → 今日用药情况」查看当日计划时段。

在「用药管理 → 用药清单」的「AI 病历识别」区域，可选择或上传 PDF、PNG、JPEG 病历资料并点击「AI 识别」（调用 `GET /api/v1/files/{id}/medication-recognition`，本人或具备 `files:read` 权限的家属可用）。配置外部模型时返回识别出的药品列表、过敏史与诊断；未配置（`LLM_MODE=mock`）时提示「AI 识别未配置」。勾选识别结果点击「填入清单」时，未明确写出服药时刻的条目会按每日次数填入默认时刻（1 次 `08:00`、2 次 `08:00/20:00`、3 次 `08:00/12:00/18:00`、4 次 `08:00/12:00/16:00/20:00`），核对后点击「保存并生效」。在「用药管理 → 病例资料」可上传和查看资料原件。

在「用药管理 → 今日用药情况」可对当日计划时段直接点击「已服」「没服」（需选择漏服原因并可填备注）或「不确定」，并在下方「服药记录」查看记录与漏服原因。

## 保存设置与日常启动

如需每次启动使用固定配置，可从 `backend/.env.example` 复制为 `backend/.env`（不要提交 `.env`）并按需配置。PowerShell 进程中的同名环境变量优先于 `.env`。

```dotenv
PORT=8000
CAS_RETRAINED_BUNDLE=data/models/cas-dl2-retrain-20261124
# 如需启用外部模型识别与对话，将 LLM_MODE 改为 real 并填写以下三项
LLM_MODE=mock
LLM_BASE_URL=
LLM_MODEL=
LLM_API_KEY=
```

基础演示与外部模型模式可在仓库根目录运行 `.\start.cmd`（macOS/Linux 运行 `./start.sh`）。启用本地 CAS 模型预测时，使用上面的 `--group cas` 启动命令。关闭本地 CAS 模型预测时，删除或注释 `.env` 中的 `CAS_RETRAINED_BUNDLE`，在设过该变量的 PowerShell 中执行 `Remove-Item Env:CAS_RETRAINED_BUNDLE -ErrorAction SilentlyContinue` 并重启服务。

## 模型文件与问卷流程

模型包内容与加载方式见[CAS 接入与验收](CAS接入与验收.md#模型包与依赖)。

在 `backend` 目录运行以下命令。`CasModelTests` 会加载权重并对照 `reference_cases.json` 校验预测：

```powershell
uv run --locked --group cas python -B -X utf8 -m unittest discover -s tests
```

在网页选择虚构患者本人进入「我的 → 依从性类型」，无草稿且未提交问卷时点击「开始评估」并确认隐私说明弹窗，按一屏一题向导作答（Q1–Q3、Q5–Q7 可选「无法判断」，选填部分 Q5–Q8 可直接跳过）。本人提交后自动生成结果并展示按题解读卡片（页面不展示 CAS 分数与分型代码）；若已有已提交问卷但未生成结果，页面提供「生成结果」按钮。更多规则与测试位置见[CAS 接入与验收](CAS接入与验收.md)。
