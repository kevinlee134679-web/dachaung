# S04 单次对话与减负

应用 0.4.0、schema 0007。适用总 Prompt v1.1、flow-v0.1、public-o-v0.5、A-v0.4、B-v0.4、C-v0.2、deferred-v0.1 及其继承来源。默认本机 127.0.0.1、demo 身份、mock 模型、single_pass。G 与 O/A 原有 75 个接口保留，另注册 39 个 B 契约入口。部分入口按当前依赖明确拒绝。

## 独立演示

在工程根目录执行。将示例路径换成尚不存在的隔离目录，使用空闲端口。

```powershell
$env:DATABASE_PATH = Join-Path (Get-Location) 'test-output/s04-new-demo/demo.sqlite3'
$env:PORT = '8124'
$env:HOST = '127.0.0.1'
$env:AUTH_MODE = 'demo'
$env:LLM_MODE = 'mock'
$env:DIALOGUE_PIPELINE = 'single_pass'
.\.venv\Scripts\python.exe -X utf8 -m medplatform init-db
.\.venv\Scripts\python.exe -X utf8 -m medplatform seed-demo
.\.venv\Scripts\python.exe -X utf8 -m medplatform serve
```

1. 打开 [隔离演示首页](http://127.0.0.1:8124/)，选择演示患者甲，进入「支持服务 → AI 情感支持」。可以自由对话，也可以打开当前演示身份对应的虚构案例。输入并显式发送一句虚构消息。「今日用药确认」通向原 O/A 页面。
2. 展开「自评与沟通线索」保存描述性自评，或查看带时间的本人原话与模型线索。发送后可展开「本轮来源与沟通说明」。医学资料不足和未启用支持强度映射均按实际状态显示。
3. 本人可使用「使用极简模式」和「恢复普通模式」。到期后的 GET 只投影为普通模式。有会话的到期历史可通过受控 A7 任务执行入口登记。显式 `s03-maintain` 在同库消费权威通知，维护到期邀请或建议。
4. 退出后选择演示管理员，在「我的」进入情感支持演示控制台。可以读取三份虚构案例的开场草稿、检查 mock 配置、选择白名单配置及触发受控故障。开场草稿由演示者复制，患者本人决定是否发送。状态事件可以演示邀请，周期节点按 O 实际启用时间和 +7/+28 天起各 24 小时的窗口核对。自动运行器未启用。
5. 示例故障选择「空响应」，使用本案例和独立场景运行号触发。回到同案例发送时，失败后历史保留原消息，可从「重试原消息」使用原快照和剩余预算。结果未知只允许核查。演示重置由管理员明确确认，限定当前案例，与待执行 A 任务取消协调。含 C 关联或在途未核清操作的案例拒绝重置。

## 数据与权限

- `0007_support_dialogue.sql` 追加 B 会话、消息、生成、分次状态、知识版本、策略与运行事实。旧 0001–0006 按原字节及校验和保留。既有库请先确认路径、停对应服务并备份，再明确运行 `migrate`。本批迁移验证使用 S03 库的独立副本，原隔离库仍为 0006。正常启动通常只检查就绪。
- 写请求沿用同源 Cookie/CSRF 和幂等。本人身份由 O 核验，家属需要逐项授权。消息接受和发布分别使用短事务，中间释放 SQLite 写锁。每次网络尝试有统一预算预留。S04 实际只使用本地 mock，整轮预算、原话、快照、版本、用量状态与失败/未知状态均可追溯。
- B2 支持关键词或标签检索及版本历史。患者医学查询仅考虑适用、有效、已审核版本。演示库没有已审核医学资料，审核通过入口需要尚未接入的合格身份。测试中受控构造的审核记录仅在临时测试库内。
- A 摘要及反馈查询从 B 读取最小引用。反馈缺失、受限和 C 未接入独立表示。B33 检索失败和 B30 导出使用业务错误或最小字段，导出包含模拟与版本标记。浏览器用文本节点展示原话和模型输出。

## 接续边界

- OpenAI 兼容适配使用可注入传输验证参数、结果状态及用量。默认服务没有注册实际外部传输。缺供应商配置、验证或授权时，真实调用和探测不可用。
- B25 在显式维护中消费可信同库通知。当前无获准自动触发规则，受控状态邀请由演示场景生成。B26 无已启用的 B 投递，晚到演示只保留本地模拟审计。B25/B26/B27 的外部可信身份与签名未启用，患者及普通演示管理员请求不能充当模块。C 申请、派发和积分属后续阶段。
- 无强度映射时 B15 返回 `not_configured`、空强度及原因。对话候选和本人主动模式已可用。自动干预及无方法时创建需要强度的可执行建议，等待研究依据或契约增量。CAS、医学分类、量表、临床阈值及项目紧急支持资源仍待专项。
- 未绑定邀请允许空会话 ID。现行 A 到期载荷要求会话 ID，因此显式维护直接按当前持久记录确认失效，避免构造会话 ID。独立的邀请展示写入口仍待确认。B29 保持 A 原 FeedbackSource 结构，单次窗口能装入结果时可读，超页或带游标明确返回 503 及缩小窗口提示，续页结构待确认。
- 当前网页及自动化验证范围见同目录 `verification.json`。真实医疗或研究验证按各自条件和后续明确阶段授权实施。
