## 使用与核验

1. 先核对交付方给出的 ZIP SHA256，再解压。使用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '实际文件路径'` 对照 `SHA256SUMS.txt`。包内清单不包含自己的校验值，整包校验值由外部提供。
2. 优先由 Git bundle 恢复 develop，`git rev-parse HEAD` 应与 `发放清单.json` 的 `handoff_commit` 一致。远程可读也可获取 `runtime_commit`，分支是 develop。GitHub 访问权由项目负责人授予。 [仓库](https://github.com/kevinlee134679-web/dachaung.git)
3. 在 Windows x64 以 Python 3.14.10 和 Git 运行，Node 24 用于前端测试。首次安装锁定依赖需能访问包源或另备相同平台的完整 wheel。演示只用本机模拟模式和新虚构数据库。 [开发者手册](接手使用与后续开发交接_v2.0.md)
