# 新成员使用 GPT 自动接手指南 v2.0

这份指南适合第一次运行 dachaung 的同学。你可以用自己的 Windows 电脑和本机 Codex 完成安装。网站使用虚构患者和模拟服务，当前版本为 **0.5.6 / schema0014**。

## 1. 收到文件后

1. 把接力 ZIP 保存到自己的电脑，核对交付方给出的 SHA256，在资源管理器中选择「全部解压」。看到四份说明、`发放清单.json`、`SHA256SUMS.txt` 和 `code/dachaung-develop.bundle`。请保留 ZIP 和 bundle。 [文件清单](接力包说明.md)
2. 打开本机支持 Codex 的桌面应用，用自己的账号正常登录。选择一个自己允许 Codex 操作的专用项目工作区，例如用户目录下面的一个新项目文件夹。把解压后的路径告诉 Codex。网页问答只能协助解释，实际执行请在具有本机文件和终端权限的 Codex 会话进行。 [桌面应用下载](https://chatgpt.com/download/) · [Codex 登录说明](https://developers.openai.com/codex/auth/)
3. 用记事本打开 [首次接手指令](首次接手指令.txt)，全选、复制并发给 Codex。附上两条信息：接力包解压路径、你允许创建工程的目录。它应当实际运行安全步骤，并把工程、演示库、访问网址、验证结果和双击入口的位置交给你。

第一次安装 Python 锁定依赖通常需要网络。Git bundle 可以离线恢复全部代码历史，项目演示不需要模型 API Key。工具缺失时，请按官方安装程序或 Codex 的具体说明安装。密码、令牌和其他私有文件由你自己保管。

## 2. 怎样判断成功

- Codex 给出可核对的完整提交哈希，与你解压得到的 `发放清单.json` 一致；使用 GitHub 运行代码时，核对清单注明的运行基线。
- 能打开本机网址，如 `http://127.0.0.1:8000/`。进入「演示患者甲」，在「我的」找到问卷和报告，在「支持服务」找到支持对话与社会支持。
- 健康页报告 **0.5.6** 和存储就绪，终端的数据库检查报告 **0014**。页面能看到虚构资源。新库中的报告和积分历史随操作产生，空账本起始为 0。
- Codex 给出一个实际可双击的 `启动演示.cmd`，记录它对应的工程和数据库路径。按 Ctrl+C 停掉它自己启动的服务后，重新启动并确认原测试数据仍在。
- 需要独立复现更完整的用药记录、家属授权、派发、反馈、同辈和兑换时，按开发者手册第 5、7 节操作。 [完整交接](接手使用与后续开发交接_v2.0.md)

## 3. 明天怎样打开

进入上一步记录的入口目录，双击 `启动演示.cmd`，保留启动窗口，再打开它打印的同一个本机网址。网站会话若已到期，重新选同一个虚构身份即可。遇到端口冲突，将报错交给 Codex 核对原服务与原库；若是其他应用，由 Codex 另选端口并更新你自己的启动入口。

## 4. 出现问题或更换 Codex 对话

把错误文字、实际工程路径、演示库位置及你正在操作的页面发给本机 Codex。优先核对原路径、原库和版本。网络失败先核对包源或离线 bundle，权限错误先查当前身份和授权。

新开 Codex 会话时，可发送下面这段，再附上记录的工程目录与本机接手结果文件：

```text
请在我指定的现有 dachaung 工程恢复接手上下文。先读取 v2.0 交接手册、发放清单、R0041/R0042、版本登记、有效契约和我本机的接手结果。核对当前 Git、应用、schema 和演示库，已有同库服务可复用。先报告已完成、模拟边界和待确认事项。本次仅恢复演示与上下文，涉及 S06、真实机构、外部身份或正式部署的工作须等负责人另行授权。
```

平台当前通过的是本地虚构演示审计。用药示例、模拟药师、匿名同辈和兑换权益都用于验证系统流程。涉及真实患者、诊疗、真实服务或部署的工作请先找负责人。
