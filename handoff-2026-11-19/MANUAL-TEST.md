# 大创项目网页人工验收操作单

按 [《搭建与网页使用路径》](USE.md) 启动后，三套站点各有独立的虚构数据库，仅在当前电脑的浏览器打开。请用虚构药名、剂量、叙述和附件。

| 入口 | 用途 | 初始状态 |
| --- | --- | --- |
| [主演示站](http://127.0.0.1:8131/) | 本人、家人、管理员和全流程 | 四个虚构身份已准备，正式记录由你操作生成 |
| [用药报告场景](http://127.0.0.1:8132/) | 验证已到时段、本人报告和统计快照 | 14 个已到时段、10 次本人确认 |
| [积分兑换场景](http://127.0.0.1:8133/) | 验证积分来源、订单和模拟履约 | 83 分，足以兑换 30 分权益 |

## 主站流程

1. 选择「演示患者甲」并点「管理自己的用药」。依次打开首页、用药管理、支持服务、积分权益和我的。返回首页观察近期服务。
2. 在「我的 → 八题问卷」填写并提交，走到描述性画像。可以用「不清楚」演示未知值。画像应显示 CAS 尚未适配。
3. 在「用药管理 → 药品资料」新增虚构药品，再去「资料核对」保存并提交草稿。以本人明确确认后，到「今日安排」查看时段。需要直接核查过去已到时段的报告时，切换到下方报告场景。
4. 在「支持服务 → 开始自由对话」发送一句虚构消息。试用极简模式、刷新、再主动恢复。可退出后切为「演示管理员」，在「我的」里选择 mock STAR，执行一次模拟模型探测。切回患者再发一轮，对照两轮流水线和历史记录。
5. 患者从「支持服务 → 社会支持」打开「药学咨询资源（模拟）」。准备服务问题、保存草稿、明确确认共享，再明确提交正式服务。记下页面给出的服务编号和派发任务编号。管理员在「我的 → 社会支持演示控制台」执行一次模拟派发，再用原服务编号依次记录处理中、完成。切回患者，通过「首页 → 近期服务 → 查看这条服务」查看同一编号，并提交自愿反馈。
6. 患者到「我的 → 家庭授权」生成一次性绑定码。切换「演示家人」并兑换。切回患者只勾选「支持对话历史（只读）」并保存。家人在「当前管理对象」选择患者甲后可读取对话，页面没有发送按钮。切回患者撤销授权，再以原家人会话刷新或再次登录查看。
7. 同辈流程可从「支持服务 → 匿名同辈」进入。以虚构内容准备入组申请，体验待受理、管理员模拟登记、匿名发言待审、审核公开及主动退出。详情见项目演示脚本。

同一浏览器切换角色时先点「退出」。如果要保留一个家人会话以检查即时撤权，可以在常规浏览器与 InPrivate 窗口分别登录两个角色。

## 补充场景

- **报告场景**。在 8132 登录演示患者甲，进入「我的 → 用药报告」。把生成器输出的 window_start 和 window_end 转为北京时间日期填入，结束日期不含当天。明确刷新后，核对 14 个已到时段、10 次本人确认及约 71.4% 的确认比例。开盒记录为独立证据。
- **积分场景**。在 8133 登录演示患者甲，打开「积分权益」，核对来源和 83 分余额。选择 30 分权益并明确兑换，核对余额为 53 分、扣分一条、原订单可读取。需要验证履约时，使用演示管理员明确执行同一订单的模拟履约。

## 继续使用已操作的记录

三个入口按 USE.md 启动。以后服务停止时，在准备好的应用目录重新执行对应一行，打开原网址继续查看已保存的记录。每行启动一个服务，分别在终端中运行。

```bat
start.cmd serve --database "test-output\repro-demo\main\demo.sqlite3" --port 8131
start.cmd serve --database "test-output\repro-demo\analytics\demo.sqlite3" --port 8132
start.cmd serve --database "test-output\repro-demo\points\demo.sqlite3" --port 8133
```

反馈问题时记录网址、虚构角色、页面、点击顺序、期望和实际结果。截图可遮住绑定码及会话信息。
